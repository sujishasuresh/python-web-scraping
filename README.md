# Python Web Scraping

A simple web scraping project using Python, Requests, and BeautifulSoup to extract information from a website.

## Technologies Used

* Python
* Requests
* BeautifulSoup

## Features

* Sends HTTP requests to a website.
* Parses HTML content using BeautifulSoup.
* Extracts the page title, quote, and author.
* Displays the extracted information in the terminal.
